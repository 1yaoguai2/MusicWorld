# 2026-10-28

## 修复：自动切歌报 ERR_CACHE_OPERATION_NOT_SUPPORTED

- 根因：Chromium 媒体缓存缺陷——切歌时上一个 Range 请求被中断后写 HTTP 缓存失败；IIS 默认不发明示 Cache-Control（启发式缓存路径）最易触发。Articulate 社区证实调整服务端媒体缓存策略后不可复现。
- 修复双层：
  1. `web.config`：`<location path="music/lyrics">` + `clientCache UseMaxAge 30天`（只作用媒体目录，html/js/css 改版即生效）
  2. `js/app.js`：audio error 事件兜底——服务器 URL 曲目失败且未重试过时，URL 加 `?mwretry=时间戳` 换缓存键重试一次（`state.errorRetried` 防循环）
- 实测：加载 5 首、播放、ended 切歌、错误后自动重试恢复、回归切歌，全部通过。
- 技能同步：pitfalls.md 新增 D8、assets/web.config 加 location 模板、SKILL.md 第 7 节 IIS 要点扩充；云端「SKILL」文档同步更新（注意：insert 内容里写 `<tag>` 会被校验器拒，实体转义 `&lt;` 在代码块里也可能原样显示，直接去掉尖括号用中文描述节点名最稳）。
