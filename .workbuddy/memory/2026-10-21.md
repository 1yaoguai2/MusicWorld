## 本地静态音乐播放器（MusicWorld）

从零搭建了纯静态单页音乐播放器，无需框架、无外部依赖：

- `index.html` + `css/style.css`（CSS 变量实现日/夜双主题）+ `js/core.js`（扫描/LRC 解析/ID3 封面解析/localStorage/IndexedDB）+ `js/app.js`（播放控制、歌单、渲染）
- 功能：manifest 自动加载或 File System Access 选文件夹（handle 存 IndexedDB 可恢复）、LRC 歌词同步滚动高亮、MP3 内嵌封面提取（ID3v2.3/2.4 APIC）、四种播放模式（列表循环/单曲循环/随机/顺序）、自建歌单（增删改、加入歌单）、搜索、播放队列、快捷键
- 目录约定：`music/` 放音频，`lyrics/` 放同名 .lrc 歌词
- 辅助：`tools/scan.py` 生成 manifest.json；`tools/server.py` 支持 Range 的本地服务器；`start.bat` 一键启动
- 测试：用 playwright-core + 系统 Edge headless 验证了加载、播放、歌词推进/点击跳转、歌单、主题切换、file:// 直开，全部通过
- 踩坑：`el.pbInfo` 忘记在 DOM 引用表中定义导致初始化中断；`[hidden]` 会被类选择器 display 覆盖，需 `[hidden]{display:none!important}`
- 验证方法：Edge headless `--screenshot` 可用但 `--dump-dom` 输出为空；playwright-core 用 `channel: 'msedge'` 免下载浏览器，NODE_PATH 指向 `C:/Users/x/.workbuddy/binaries/node/workspace/node_modules`

## IIS 自动读取目录（用户已部署 IIS）

- 新增 `MW.listWebDirectory` / `MW.scanServerLibrary`（core.js）：fetch 目录 URL → DOMParser 解析 `<a href>` → 递归（限深 4）收集音频与歌词；兼容 IIS 目录浏览 / nginx autoindex / Apache / Python http.server
- 加载优先级：manifest.json → 服务器目录扫描 → 空状态 + 诊断提示（`showAutoHint` 按 403/404/empty 给出 IIS 操作指引）
- 新增根目录 `web.config`：IIS `<directoryBrowse enabled>` + defaultDocument(index.html) + 冷门音频 MIME（flac/ogg/opus/aac/aiff/ape/lrc）；注意 directoryBrowse 节在未安装「目录浏览」角色功能时会 500.19
- 判定"是否目录列表"不能只依赖 `../` 链接（Python http.server 的列表没有父目录链接），改为「解析到条目 or 页面标题含 Index of/Directory listing or 有 ../」
- 纯文本歌词支持：parseLrc 无时间标签时返回 `{plain:true}`，逐行展示可手动滚动，禁用点击跳转与自动高亮；用户的真实文件「琵琶曲(沈腾马丽对唱版)-王野川」.mp3 + .txt 已验证通过
- server.py 加 QuietServer 忽略浏览器切歌导致的 ConnectionResetError
