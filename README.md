# MusicWorld · 本地音乐播放器

一个纯静态的单页音乐播放器，无需安装、无需联网。白天 / 夜间双主题，支持歌词同步滚动、自建歌单、单曲循环 / 列表循环 / 随机播放。

```
MusicWorld/
├── index.html          播放器主页面
├── web.config          IIS 配置（目录浏览 + 音频 MIME）
├── css/style.css       样式（含日夜双主题变量）
├── js/core.js          扫描、LRC 解析、ID3 封面解析、本地存储
├── js/app.js           播放控制、歌单、渲染与交互
├── music/              ← 把你的音乐放这里
├── lyrics/             ← 把同名 .lrc 或 .txt 歌词放这里
├── tools/scan.py       生成 manifest.json（可选）
├── tools/server.py     本地静态服务器（支持音频拖动）
└── start.bat           一键启动（Windows）
```

## 快速开始

### 方式一：一键启动（推荐，Windows）

双击 `start.bat`。脚本会自动扫描音乐目录、启动本地服务器并打开浏览器。

### 方式二：直接打开网页

双击 `index.html`：

- **Chrome / Edge**：点击右上角「导入文件夹」并授权根目录（含 `music` 与 `lyrics`），授权会被记住，下次打开点「恢复上次的音乐库」即可。
- **Firefox / Safari 等其他浏览器**：同样点「导入文件夹」，会自动降级为系统目录选择框（每次打开需重新选择）；空状态页的「选择音频文件」可同时勾选音频和同名歌词文件一起导入。

### 方式三：部署到 IIS / nginx 等服务器

把整个项目目录作为站点根目录部署。页面打开后会**按顺序自动**尝试三种方式读取音乐：

1. 读取 `manifest.json`（推荐，最可靠）
2. 自动扫描 `music/`、`lyrics/` 目录列表（需要服务器开启目录浏览）
3. 都不可用时显示空状态，并给出具体原因和解决步骤

**IIS 具体步骤：**

1. IIS 管理器 → 添加网站，物理路径指向本项目目录（或直接把项目放进已有的站点目录）。
2. 项目里已附带 `web.config`，作用是启用**目录浏览**并补充 flac/ogg 等音频的 MIME 类型。把 `music` 和 `lyrics` 目录的「目录浏览」打开后，刷新网页即可自动读取全部歌曲（支持子文件夹递归）。
   - 若打开站点报 `500.19` 且指向 `directoryBrowse` 节：说明服务器未安装「目录浏览」角色功能，按错误页提示安装，或删除 `web.config` 里 `<directoryBrowse ... />` 那一行。
3. 也可以不开启目录浏览，改为在服务器上运行 `python tools/scan.py` 生成 `manifest.json`，效果相同且更可靠。

**nginx / Apache：** 目录列表（autoindex / FancyIndexing）开启后同样支持自动扫描；或者直接用 `scan.py` 生成清单。

> 提示：`manifest.json` 与目录扫描二选一即可，页面会自动优先使用清单。改完 `web.config` 后建议重启站点或执行 `iisreset`。

### 方式四：手动起本地服务器

```bash
python tools/scan.py      # 生成 manifest.json
python tools/server.py    # 启动 http://127.0.0.1:8000
```

## 放歌与歌词

- 音频放在 `music/`，支持子文件夹（会按目录递归扫描）。
  格式：mp3 / flac / wav / ogg / m4a / aac / opus / wma / aiff / ape。
- 歌词放在 `lyrics/`，**文件名与音频同名**，扩展名 `.lrc` 或 `.txt`：

```
music/周杰伦 - 晴天.mp3
lyrics/周杰伦 - 晴天.lrc
```

LRC 支持标准 `[mm:ss.xx]` 时间标签、一行多标签、`[ti:]` `[ar:]` 元信息，以及增强格式（会自动忽略 `<mm:ss.xx>`）。

`.txt` 歌词没有时间标签也能用：会以纯文本模式展示在歌词面板，可手动滚动阅读（无法随播放进度高亮）。

## 功能

| 功能 | 说明 |
| --- | --- |
| 日夜主题 | 右上角太阳 / 月亮按钮切换，选择会被记住 |
| 歌单 | 「全部音乐」「我喜欢」为内置；可新建、重命名、删除自建歌单 |
| 加入歌单 | 歌曲行右侧 `+` 按钮，或正在播放面板的「加入歌单」 |
| 播放模式 | 列表循环 / 单曲循环 / 随机播放 / 顺序播放，点击播放条最左侧按钮切换 |
| 歌词 | 右侧面板实时高亮并滚动，点击任意歌词行可跳转 |
| 封面 | 自动读取 MP3 内嵌专辑封面，无封面时按歌名生成渐变色块 |
| 搜索 | 按歌名、歌手、专辑、文件名筛选当前歌单 |
| 播放队列 | 播放条右侧列表按钮，可查看并跳转队列 |
| 快捷键 | 空格播放/暂停 · ← → 快退/快进 5 秒 · ↑ ↓ 音量 · M 静音 · Ctrl+← / Ctrl+→ 上/下一首 |

歌单、收藏、音量、主题、播放模式都保存在浏览器 localStorage 中。

## 常见问题

**歌词没有显示？**
确认 `lyrics` 文件夹里的歌词与音频同名（只差扩展名）。文件名里的序号（如 `01.` ）会被忽略，因此 `01 晴天.mp3` 可以匹配 `晴天.lrc`。

**歌名 / 歌手显示不对？**
程序会先按 `歌手 - 歌名` 推断文件名，MP3 则优先读取内嵌标签。若仍不对，可在文件名中改用 `歌手 - 歌名` 格式。

**播放失败？**
多为格式不被浏览器支持（如 ape、wma 的部分编码）。转换成 mp3 / flac / m4a 即可。

**换了音乐文件夹后自建歌单空了？**
歌单按文件路径记录，换库后需要重新添加。
